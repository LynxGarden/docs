## Workflow

```bash
supabase start          # local stack (ports remapped +1000 in config.toml)
# ...add a new migration file...
supabase db reset       # REQUIRED after adding a migration — applies it + reseeds
supabase db push        # deploy to the hosted project (afrqrnipjrnwnwxrfjvx)
```

<Callout type="warn">
After adding a migration, `supabase db reset` (not just `start`) — otherwise the
new file isn't applied locally.
</Callout>

## Verifying RLS

Every checkpoint's RLS is verified with a **rolled-back** two-tenant / two-person
`psql` test (simulating users via `set local role authenticated` +
`request.jwt.claims`) before the migration is committed. The test asserts both the
positive paths and the denials (cross-person, cross-tenant), then `rollback`s so no
state persists.

## Cloud

Hosted project ref `afrqrnipjrnwnwxrfjvx`; all migrations pushed and live; no edge
