## The flow

1. Open app → the assigned program shows as a **list of sessions** → a badge marks
   which was completed last (`assignment_sessions.last_completed_at`) → pick the next.
2. Enter a session → ordered list of exercises.
3. Per exercise:
   - **See the target** — the prescription snapshot.
   - **Watch the video** (`url_launcher`).
   - **See last time's actuals** ← the priority feature.
   - **Enter actuals** — sets / reps / weight / time.
   - **Swap** the exercise (tag-driven suggestions from the same library).
4. **Mark session complete.**

Online-only in v1 (clear banner when disconnected).

## "Last time" — first-class

Backed by a per-client, per-exercise history in **`logged_entries`**. When an
exercise renders we fetch the most recent prior entry for `(person_id,
exercise_id)` and show it beside today's inputs. The index below is load-bearing:

```sql
create index logged_entries_last_time_idx
  on public.logged_entries (person_id, exercise_id, logged_at desc);
```

### `logged_entries`

| Column | Notes |
| --- | --- |
| `tenant_id` | tenant isolation |
| `person_id` | whose history this is |
| `exercise_id` | for the "last time" lookup (kept stable across swaps) |
| `assignment_exercise_id` | the log's context (nullable) |
| `entry_type` | default `strength_set` (extensible) |
| `set_index`, `reps`, `weight`, `time_seconds` | actuals |
| `data` | jsonb — future entry types |
| `logged_by` | who logged it (client, or staff on-behalf) |
| `logged_at` | timestamp; drives "last time" ordering |

## RLS

- **Client** reads/writes **their own** rows (`person_id = logged_by = me`).
- **Staff** read the tenant's clients' rows and may **log on behalf**
  (`logged_by = me`, any `person_id` in tenant).
- A client cannot log for another person, and cannot spoof `logged_by`.

## RPCs

Clients own their assignment but **cannot write `assignment_*` directly** (those
tables are staff-write only). So the two write actions in the runner go through
`SECURITY DEFINER` RPCs that authorise **owns-the-assignment OR staff**:

- **`complete_session(assignment_session)`** — stamps `last_completed_at = now()`.
- **`swap_assignment_exercise(assignment_exercise, new_exercise)`** — repoints the
  snapshot to a different library exercise, copies the new `name`/`video_url` into
  the snapshot, and records the original in `swapped_from_exercise_id` (kept stable
  across repeated swaps via `coalesce`), so `exercise_id`-keyed "last time" history
  stays uncorrupted.
