Checkpoint **CP9** · App: `features/notifications` · Backend migration:
`notifications`.

A per-recipient, realtime in-app feed. Rows are **generated server-side by
SECURITY DEFINER triggers** — never written by the client — so they can't be
spoofed:

- a coach **comment** on a client's exercise → notifies the **client**;
- a coach **like** → notifies the **client**;
- a client **difficulty rating** → notifies their **coach**.

## Data

`notifications` (`recipient_id`, `actor_id`, `type`, `title`, `body`, `data` jsonb,
`read_at`). RLS: the recipient reads + marks their own; inserts happen only via the
triggers. Realtime-published.

## App

`NotificationsRepository.stream(recipientId)` (realtime) + `markRead` / `markAllRead`.
`notificationsProvider` (StreamProvider) and `unreadNotificationsCountProvider`
(badge). `NotificationsScreen` is reached from **Settings → Notifications** (the row
shows the unread count); tapping a notification marks it read.
